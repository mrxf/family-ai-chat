# 找专门的助手（角色助手）

除了默认的小暖，首页还提供按场景预设好提示词与提问建议的专门助手（由家庭服务端配置）。

## 如何进入与切换
1. 回到「新对话」首页（点侧栏/抽屉的「新对话」，或对话页右上角新对话图标；电脑端按 `⌘/Ctrl + N`）。
2. 在首页下方找到 **「找专门的助手」** 横向卡片栏，点选想要的助手即可开启对应角色的对话。
3. 助手首页会展示它的简介与几条快捷提问建议，点一下即可直接发送，也可以自己打字提问。
4. 在助手页面底部同样可以点「开启隐私对话 · 助手名」，以隐私模式和该助手交流。

## 与小暖普通对话的关系
- 切换助手后，对话顶部标题会显示该助手的名称；点顶部标题仍然可以按需切换底层模型。
- 普通模式下依然会结合小暖对你的长期了解；如果只想临时聊不留记录，请使用隐私对话。
- 想切回默认小暖，点「新对话」即可回到小暖首页。
