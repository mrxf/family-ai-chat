# 首页与对话交互卡片

小暖在合适场景下会直接用可视化交互卡片来呈现信息，而不是只发大段文字或难看的表格。

## 支持哪些卡片类型
1. **天气卡**：展示当日及未来几天天气、气温、体感、湿度、风力。
2. **互动待办清单（Todo）**：采购清单、打包清单、步骤清单等，**可以直接点击打勾保存进度**。
3. **动态资讯 / 新闻列表（Feed）**：汇总新闻简报或有序资讯，适合固定到首页配合「AI 定时任务」定期滚动更新。
4. **交互式图表（Chart）**：支持折线图、柱状图、环形占比图。
5. **关键指标看板（Metrics）**：大字号展示核心数据（如月供算账、体检关键指标、热量营养速览）。
6. **互动答题卡（Quiz）**：点击选项即可揭晓对错与解析。
7. **交互式询问卡片**：当你的需求有多种方向时，小暖会弹出单选/多选卡片让你点选偏好（带「其他」自由输入，也可以随时点关闭跳过）。

## 卡片上可以做什么（手机端 & 电脑端通用）
在对话里的可固定卡片下方（或卡片操作栏）可执行：
- **固定到首页 / 取消固定**：把常用的清单、资讯、天气、看板钉到「新对话」首页，打开小暖一眼就能看到。
- **手动编辑**：直接打开卡片编辑器修改条目或内容。
- **查看历史版本 / 切到最新版本**：卡片经过原地更新后，可查看历史版本记录，或在旧对话里一键预览最新版本。
- **引用到新对话**：把卡片带入新对话输入框上方，围绕这张卡片继续让小暖补充、修改或分析（不污染原对话）。
- **配置定时更新**：把资讯类、数据类卡片绑定到「AI 定时任务」，让小暖按时自动刷新内容。

## 首页卡片管理
- 进入「新对话」即为首页；若已固定了卡片，顶部右侧有「AI 定时任务」快捷按钮和「刷新首页卡片」按钮。
- **直接口头让小暖管理首页**：在普通对话里可以直接说：
  - “把刚才那张卡片固定到首页” / “把首页的 XX 卡片取消固定”
  - “把 XX 卡片排到首页第一个”
  - “隐藏 / 显示首页的猜你想问”
- 注意：隐私对话中不能固定卡片，也不能通过对话管理首页卡片。
