# 设置、快捷键、账号安全与管理员边界

## 外观、字体大小与朗读语速
- **手动调整**：
  - **手机端**：左上角菜单 → 底部头像或齿轮进入「设置」，直接调整「字体大小」（小 / 较小 / 标准 / 大 / 特大）、「外观」（跟随系统 / 浅色 / 深色）和「朗读 → 语速」。
  - **电脑端**：左下角齿轮或按 `⌘/Ctrl + ,` 进入「设置 → 通用与外观」，可编辑个人资料（称呼/头像）并调整主题模式、字体大小与朗读语速。
- **直接口头让小暖调（仅影响当前发消息的设备）**：
  - 可以在普通对话里直接说“把字调大一点”“字体调到特大”“换成深色模式”“主题跟随系统”，小暖会直接帮你调好并在消息里附带撤销按钮。
  - 若只是说“字太小看不清”“太亮了”，小暖会先弹卡片请你确认想调成哪一档。
  - 注意：目前口头控制**仅支持当前设备的字体大小、深浅主题和首页卡片/猜你想问管理**；**语速、页面跳转、控制其他设备**目前还不支持口头操作，需要手动去设置里调。

## 电脑端键盘快捷键
（macOS 用 `⌘`，Windows 用 `Ctrl`）
- `⌘/Ctrl + N`：新建对话
- `⌘/Ctrl + K`：搜索历史聊天记录
- `⌘/Ctrl + ,`：打开或关闭「设置」
- `Esc`：在设置/二级页时返回上一级或回到对话；在对话中时返回首页（若在隐私对话中则退出隐私对话）
- 输入框内：`Enter` 发送，`Shift + Enter`（或 `Alt + Enter`）换行

## 账号、免输登录口令与服务器
- **入口**：手机端在「设置 → 账号 / 关于」；电脑端在「设置 → 账号与安全」。
- **修改密码**：可自行更新当前账号的登录密码。
- **生成免输登录口令**：点击「生成免输登录口令」，生成 `#xn...xn#` 格式的加密口令，发给异地家人或在自己的另一台设备复制后直接登录，省去手动输入服务器地址和账号的麻烦。
- **服务器与自托管**：在「服务器」一项可查看当前连接的是官方默认还是自托管服务器。
- **版本更新**：Android 手机在「设置 → 关于 → 检查更新」可直接检查并下载安装包更新；iOS / macOS / Windows 无内置 APK 更新入口。
- **退出登录**：退出后聊天记录保存在服务器上不会丢失，重新登录即可找回。

## 管理员功能与安全边界
- 只有带「管理员」标记的家庭账号，才会在设置里看到 **「家庭管理」** 分组，包括：
  - 「家庭成员」（创建家人账号、重置密码）
  - 「模型与供应商」（配置聊天与画图模型、默认模型、自动选模型等）
  - 「语音输入」（配置语音转文字服务）
  - 「联网搜索」（配置实时搜索服务）
  - 「用量与花费」（查看各成员与模型费用）
- **安全边界**：为保护账号安全，小暖永远不能在对话里代为执行退出登录、修改密码/个人资料、切换服务器、生成登录口令以及任何管理员操作，这些都需要用户自己在「设置」界面手动完成。
