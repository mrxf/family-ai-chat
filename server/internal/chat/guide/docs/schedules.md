# 我的日程与 AI 定时任务

小暖提供两种与时间相关的功能：**「我的日程」**（提醒人去做某事）和 **「AI 定时任务」**（让小暖按时自己在后台跑任务并更新卡片）。

---

## 一、我的日程（日程提醒）

### 如何创建
- **直接跟小暖说**（最省事）：在普通对话里直接说“明天上午 9 点提醒我吃药”“每周三晚上 8 点提醒我看体检报告”等，小暖会自动创建日程；也可以口头让小暖查询、修改、标记完成或删除日程。
- **手动添加**：进入「我的日程」页面点「添加日程提醒」，可填写标题、日期时间、重复周期（单次 / 每天 / 每周 / 每月等）及提前提醒时间。

### 在哪里查看与管理
- **手机端**：左侧抽屉底部若有未完成日程会显示日历数字徽标，点击直达；或进入「设置 → 我的日程」。
- **电脑端**：左侧栏底部日历数字徽标点击直达；或进入「设置（`⌘/Ctrl + ,`）→ 我的日程」。
- 点击某条日程可「标记已完成 / 标记此次已完成」「修改日程」「删除这条日程 / 删除整个周期提醒」；右上角「更多（…）」可「清理已完成的单次日程」。

### 手机端与电脑端的提醒差异
- **手机端（Android / iOS）**：支持**系统本地通知准点提醒**。若未开启通知权限，日程页会提示开启，或在页面右上角「更多（…）」→「检查手机通知设置」里打开。
- **电脑端（macOS / Windows）**：可以完整查看、增删改日程，但**目前不支持桌面本地弹窗通知**；日程会同步到你的手机端响铃提醒，小暖在对话里也会知晓你的近期安排。

## 二、AI 定时任务（后台自动执行）

让小暖按设定的时间周期在后台自动联网查新闻、整理数据、生成分析，并可原地更新你固定在首页的卡片。

### 在哪里查看与管理
- **首页快捷入口**：当首页有固定卡片时，首页顶部右侧会出现定时任务图标，点击直达。
- **设置入口**：
  - 手机端：「设置 → AI 定时任务」。
  - 电脑端：「设置（`⌘/Ctrl + ,`）→ AI 定时任务」。
- **对话创建**：也可以直接在普通对话里让小暖帮你创建、暂停或修改定时任务（或针对首页某张卡片设置定时刷新）。

### 可执行的操作
在「AI 定时任务」页面可以：
- **新建 / 编辑任务**：设置任务标题、执行频率与时间、要让小暖执行的指令，以及是否绑定更新某张首页卡片。
- **启用 / 暂停**：用任务卡片上的开关随时启停。
- **更多菜单**：可「立即运行一次」「查看执行记录」「打开任务执行对话」「编辑任务」「删除任务」（删除任务不会删掉已更新到首页的卡片内容）。
