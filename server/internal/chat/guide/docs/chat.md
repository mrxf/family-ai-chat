# 日常聊天、模型、图片、语音与消息操作

## 发送消息与换行
- **手机端**：在底部输入框打字，点右侧发送按钮发送；回复过程中点同一位置的方形停止按钮可随时「停止回答」。
- **电脑端**：按 `Enter` 直接发送；按 `Shift + Enter`（或 `Alt + Enter`）换行；中文输入法选词按回车不会误发。
- **单条消息上限**：单次最多发送 100,000 字；长对话无需手动清理，小暖会在后台自动整理前情提要，老对话翻回来依然连贯。

## 切换模型与深度思考
- **切换模型**：点击聊天页面顶部中央的标题/模型名称，弹出「选择模型」列表。
  - 若家庭管理员开启了「自动选模型」，默认会按问题难易自动挑合适的模型（顶部显示「自动 · 模型名」）。
  - 也可以手动指定某个模型，当前对话会沿用该模型。
- **深度思考**：当所选模型支持推理时，输入框左下方会出现「深度思考」按钮，点亮后小暖会花更多时间仔细推演并展示思考过程。

## 拍照、发图与画图 / 改图
- **发图提问**：
  - 点输入框左下角的相机/图片图标添加图片，**一次最多发送 9 张**。
  - **手机端（Android / iOS）**：可选「拍照」或「从相册选择」。
  - **电脑端（macOS / Windows）**：直接打开系统文件选择窗口选图（不支持调用摄像头拍照）。
  - 注意：若当前模型不支持看图，发送前会提示切换支持识图的模型。
- **画图与改图**：直接在对话里说“帮我画一张……”或对对话里已有的图片说“把刚才那张图改成……”，小暖会自动调用画图功能（需管理员已开启画图模型；管理员可能设有每人每日画图张数上限）。
- **保存图片**：点小暖回复下方工具栏的下载图标「保存图片」（手机端保存到相册，macOS 保存到「照片」，Windows 保存到「图片」文件夹）。

## 联网搜索
- 只要管理员在「联网搜索」里配置好服务，询问实时新闻、天气、行情、政策等最新信息时，小暖会自动联网查证并在回复上方折叠展示参考来源，无需手动开关。

## 语音输入与语音朗读
- **语音输入**：管理员开启语音输入后，在输入框为空时右侧会出现麦克风按钮，可直接说话转文字发送（具体是边说边出字还是录完转文字取决于管理员配置）。
- **语音朗读**：点小暖每条回复下方的喇叭图标「朗读」，可听语音播报，再次点击「停止朗读」。语速可在「设置 → 朗读 / 语音朗读」里调节（很慢 / 较慢 / 正常 / 较快 / 很快）。若提示当前设备不支持朗读，需在系统设置中安装中文语音包。

## 消息操作
- **小暖的回复下方工具栏**：
  - 「复制」：复制整条回答。
  - 「朗读 / 停止朗读」：语音播报。
  - 「重新回答」（仅最后一条回复）：用当前模型重新生成。
  - 「更多（…）」：可「分享这段对话」「复制全部」「选择部分文字」（进入可自由划选的纯文本页）、「换个模型重新回答」（仅最后一条）、「删除这条消息」。
- **自己发的消息**：手机端长按气泡 / 电脑端右键气泡，可「复制」「修改后重新发送」「删除这条消息」。发送失败时点红字提示或红色感叹号可重试。
