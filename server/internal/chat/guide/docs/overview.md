# 小暖能力总览与界面导航

小暖是面向家庭成员的 AI 助手，同一账号可在 **手机端（Android / iOS）** 和 **电脑端（macOS / Windows）** 使用，聊天记录、记忆、日程、首页固定卡片与定时任务均保存在服务器上，多设备自动同步（但字号、深浅主题、朗读语速仅保存在当前设备）。

## 界面布局差异
- **手机端（窄屏）**：聊天占满全屏；点左上角菜单图标打开左侧抽屉（可看历史对话、搜索、点底部头像或齿轮进入「设置」）；右滑或点左上角/返回可回到首页或对话。
- **电脑端（宽屏）**：左侧常驻侧栏（聊天列表 / 设置导航栏之间切换），右侧为聊天或设置工作区；支持键盘快捷键（详见 `settings_and_shortcuts`）。

## 核心能力地图
1. **日常对话与多模型**：支持自动选模型或手动切换模型、深度思考、联网查实时信息、拍照/选图提问（最多 9 张）、画图与改图、语音输入与语音朗读（详见 `chat`）。
2. **小暖记住的事（长期记忆）**：自动或手动记住你和家人的长期信息，换模型也认识你；支持「从其他 AI 导入」（详见 `memories`）。
3. **隐私对话与分享**：支持不留记录的隐私对话；普通对话可「共享给家人」多人协作、生成「分享短口令」或「生成长图海报」（详见 `privacy_and_share`）。
4. **我的日程与 AI 定时任务**：说句话就能定日程提醒（手机端支持本地通知提醒）；还能设置后台 AI 定时任务，按时查资讯并更新首页卡片（详见 `schedules`）。
5. **首页与交互卡片**：天气、可勾选待办清单、资讯列表、图表、指标看板、互动问答等卡片，支持固定到首页、原地编辑、看历史版本、引用到新对话继续聊（详见 `home_and_cards`）。
6. **专门的助手**：首页底部可切换不同角色设定（详见 `assistants`）。
7. **个性化与快捷操作**：可手动或直接口头让小暖调整当前设备的字体大小与深浅色；支持免输登录口令方便家人登录（详见 `settings_and_shortcuts`）。

## 常见入口速查
- **新对话**：点侧栏/抽屉顶部「新对话」按钮，或对话页右上角新对话图标（电脑端 `⌘/Ctrl + N`）。
- **搜索聊天记录**：点侧栏/抽屉顶部放大镜图标（电脑端 `⌘/Ctrl + K`）。
- **管理单条历史对话**：手机端长按对话条目、电脑端右键点击，可「重命名」「置顶/取消置顶」「共享给家人 / 管理共享成员」「删除 / 退出共享」。
- **进入设置**：点侧栏/抽屉左下角头像或齿轮图标（电脑端 `⌘/Ctrl + ,`）。
