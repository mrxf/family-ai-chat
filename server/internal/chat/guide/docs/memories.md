# 小暖记住的事（记忆管理与从其他 AI 导入）

小暖会在日常对话中记下关于你和家人的长期情况（如称呼、健康与用药、家人、口味与回答偏好、近期在做的事），换模型聊天也同样认识你。记忆仅你自己可见，不会在家庭共享对话里泄露给其他家人。

## 如何查看与管理记忆
- **手机端**：点左上角菜单图标 → 底部「设置」（头像或齿轮）→「小暖记住的事」。
- **电脑端**：点左下角「设置」（或按 `⌘/Ctrl + ,`）→ 左侧设置栏点「小暖记住的事」。

在「小暖记住的事」页面可以：
- **开关记忆**：切换顶部「让小暖记住我」开关。关闭后会暂停新记和使用记忆，但已有的记忆会保留，仍可查看和管理。
- **手动添加**：手机端点底部「手动添加」按钮，电脑端点右上角「手动添加」按钮（每条 1～200 字，可选分类）。
- **修改或忘掉单条**：手机端点按该条记忆弹出菜单选「修改」或「忘掉这条」；电脑端可直接点条目右侧的编辑 / 删除图标。
- **回看原对话**：如果某条记忆来自历史聊天，点条目下方的「来自对话」可直接跳回当时那段对话。
- **全部清空**：点右上角「更多（…）」→「全部清空」（不可恢复，但聊天记录会保留）。

## 如何从 ChatGPT / Gemini / Claude / 豆包等导入记忆
1. 进入「小暖记住的事」。
2. 点页面上的「从其他 AI 导入」或「从 ChatGPT、Gemini 等导入」（也可点右上角「更多（…）」→「从其他 AI 导入」）。
3. **第 1 步**：点「一键复制这段话」，把它发给原来的 AI，让对方把关于你的记忆按分类整理成纯文本列表。也可以直接复制 ChatGPT「设置 → 个性化 → 记忆」或 Gemini「保存的信息」里的文字。
4. **第 2 步**：把内容粘贴进输入框（可点输入框上方的「粘贴回答」按钮），然后点底部「让小暖整理」。
5. **等待整理**：小暖会在后台自动分段整理、与已有记忆去重并标出需要更新的条目；整理过程中可以离开页面去做别的事，回来会自动继续显示进度或结果。
6. **第 3 步（确认导入）**：整理完成后会展示预览列表，勾选要保留的条目（点条目文字可修改），最后点「导入 N 条」才会真正保存。如果记忆开关当前是关闭的，导入时会询问是否顺便打开「让小暖记住我」。

## 重要限制与常见问题
- **暂不支持直接上传 Word（`.docx`/`.doc`）或 `.txt` 文件**：导入页目前只支持**复制粘贴纯文本**，没有文件上传入口。如果原 AI 导出的是 Word 或 TXT 文件，请先打开文件复制正文再粘贴。
- **单次最多粘贴 30,000 字，单次最多预览/导入 300 条**：
  - 如果导出的内容超过 30,000 字，输入框会提示「内容超过 30000 字，请分两次导入」。
  - **解决办法 1（分批粘贴）**：按每批 2～3 万字分几次粘贴导入即可；小暖会自动与已导入的记忆去重、合并更新，不用担心重复。
  - **解决办法 2（先让原 AI 浓缩）**：把文件或长内容发回给原 AI，配合导入页第 1 步自带的提示词让它精简成「一行一件事」的列表，通常几千字就能装下，一次即可导完。
- **隐私对话不会记录记忆**：隐私对话既不读取也不写入任何长期记忆。
